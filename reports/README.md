# Reports

Generated execution artifacts belong here. The repository includes this placeholder so reviewers can see the intended structure.

Example:

```bash
pytest tests/unit -v --junitxml=reports/junit-unit.xml --html=reports/unit-report.html --self-contained-html
```

Live UI reports are not fabricated for the assessment because no real WorkFlow Pro environment/credentials were supplied. CI will produce artifacts when valid test-environment secrets are configured.
